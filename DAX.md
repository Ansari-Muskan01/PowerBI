# DAX – Data Analysis Expressions


DAX Aggregated functions : 
Aggregation functions perform calculations on multiple rows and return one result.

SUM()
AVERAGE()
MIN()
MAX()
COUNT()
COUNTA()
DISTINCTCOUNT()
